# Contributing

This repository is a **one-way mirror**. Development happens in an internal
repository, and snapshots are published here for transparency.

Pull requests cannot be accepted and issue tracking is not enabled. A pull
request opened here cannot be merged: the branch is replaced wholesale by the
next published snapshot, so any change made here would be lost.

If you have found a security issue, see [SECURITY.md](SECURITY.md).

This may change. If contributions are opened up later, this document will say
how.
